## Как устроен репозиторий

Материалы ведутся в Obsidian в формате Markdown. В репозиторий попадают только практические тесты и файлы учебного кейса. Конспекты, настройки Obsidian и резервные копии не публикуются.

В выполненных тестах сохранены исходные ответы, ревью и итоговые оценки, чтобы был виден прогресс обучения.
