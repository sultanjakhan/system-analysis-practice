## Ситуация

Клиент TradeBridge выводит деньги со своего инвестиционного счёта на банковский счёт.

Известно:

- пользователь работает через мобильное приложение;
- приложение показывает доступный остаток, ранее полученный от TradeBridge;
- пользователь вводит сумму и нажимает «Вывести»;
- backend TradeBridge проверяет пользователя, актуальный остаток и дневной лимит;
- при успешной проверке backend создаёт в базе данных заявку со статусом `PROCESSING`;
- затем backend TradeBridge передаёт платёжное поручение банковской системе;
- результат операции возвращается мобильному приложению;
- между загрузкой экрана и отправкой запроса доступный остаток может измениться;
- соединение может оборваться после создания заявки, но до получения ответа приложением.
